# SubPar-Web

A sub mediocre Perl web framework built for learning purposes. Not meant for production use — this is a personal project to better understand how web frameworks, HTTP, and PSGI work under the hood.

Feel free to criticize me!

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/mateirobescu/SubPar-Web/dev/install.sh | bash
```

## Getting Started

Create a new project in the current folder:

```bash
subpar create-project
```

Start the server:

```bash
subpar runserver
```

Or with a custom port:

```bash
subpar runserver 3000
```

## Requirements

- Perl 5.32+
- cpanm
- git
